## 🚀 Instalación Rápida

Sigue estos sencillos pasos para instalar todos los temas:

1.  **Clona el repositorio** dentro de la carpeta `themes` de tu instalación de PhpMyAdmin:

```bash
# Navega a tu directorio de temas (ejemplo en XAMPP)
cd C:\xampp\phpMyAdmin\themes

# Clona el repositorio
git clone https://github.com/userlg/PhpMyAdmin-Themes.git .
```

> **Nota:** Si prefieres, puedes descargar el ZIP y descomprimirlo directamente en la carpeta `themes`. Si tienes alguna otra configuracion en tu sistema o ubicacion de phpmyadmin entonces solo copia los temas a la carpeta donde esta PhpMyAdmin/themes

---

## ⚙️ Uso y Activación

Cambiar de tema es súper sencillo:

1.  Abre **PhpMyAdmin** en tu navegador.
2.  En la página de inicio, busca el panel de **"Configuración de la apariencia"** (generalmente a la derecha o abajo).
3.  Selecciona tu tema favorito en el menú desplegable **"Tema"**.
4.  ¡Listo! La interfaz se actualizará al instante. 🎭

También puedes forzar un tema por defecto editando tu archivo `config.inc.php`:

```php
$cfg['ThemeDefault'] = 'darkwolf'; // Reemplaza 'darkwolf' por tu tema favorito
```
